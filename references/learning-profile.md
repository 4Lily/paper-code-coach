# 学习记录与跨会话衔接

## 定位与恢复

1. 本轮明确指定的位置优先。其次沿用已有对话或档案中确认的位置、项目及完成标准。恢复时只读取当前档案及相关问题、源码或报告。信息齐全的追问无需恢复全部背景。
2. 如曾按默认位置保存档案，可检查非空 `$CODEX_HOME` 下的 `learning/paper-code-coach/profile.md`。未设置 `CODEX_HOME` 时，可在用户主目录下检查 `.codex/learning/paper-code-coach/profile.md`。练习目录沿用用户确认的位置，按当前平台解析路径。
3. 已绑定持久文件或在用同步位置时，按对应环境访问同一记录。当前环境看不到已知档案时，从当前对话或用户提供的副本恢复最少必要信息；标出旧档案不可访问。只有确认是首次训练、用户要求另建或指定迁移目标时，才建立新主档案。拿不准旧路径含义时保留原指向，先推进不依赖档案的工作。
4. 根据最新材料确定项目、模块、已完成位置、当前契约、验证范围和一个下一动作。旧待办若已有完成证据，更新为最新状态。多项目并存时按本轮明确项目操作；选择确实影响推进且资料无法消除歧义时，询问当前项目。

## 更新位置与时机

| 记录 | 内容 | 更新时机 |
| --- | --- | --- |
| 跨项目学习档案 | 目标偏好、当前项目、完成位置、能力证据与下一动作 | 首次训练缺失且位置明确，或模块验收、计划偏好改变、结束训练、主动更新背景 |
| 项目问题记录 | 已确认的练习目录内 `学习问题记录.md` 或同用途文档，保存实际疑问与解决过程 | 答疑、审查和验收出现具体学习问题时。多个项目共用文档时按项目归类 |

- 调用训练流程包含在已确认位置维护以上记录；用户关闭记录、限制写入或指定其他位置时遵从。普通论文问答、修改本技能、普通工程请求无需自动归档。修改记录和修改练习代码分别依据各自的授权。
- 写入前读取目标最新版，局部合并。已有版本控制时使用对应的版本核对机制；发现并发修改先合并。无法确定哪个条目更新时保留双方和来源，标记待核实。保留用户笔记、其他项目、有效链接和唯一证据。
- 不为练习或问题记录猜测目录。日期用用户时区，路径和链接对应实际文件；未来文件标注待创建。排除密钥、令牌及与学习无关的个人资料。

## 记录内容

学习档案沿用现有结构。按需保留以下内容：

- **目标与偏好**。区分用户明确要求、临时选择及项目默认值，标清适用范围。
- **当前训练**。论文或代码版本、实际练习路径、当前模块、必要契约、已完成步骤、卡点与问题文档。
- **能力与产出**。注明用户解释、用户实现、AI 实现或共同完成，以及证据、日期和验证范围。能解释、提示下完成、独立完成和功能实测各自判断。看不到独立完成过程时注明证据范围。
- **下一步**。写一个可直接执行的动作，附必需依赖与完成标准。例如「给位置偏移案例加一组非零起点输入，与手算角度对照」。提前结束也保存实际停点。
- **近期记录**。简短保留重要事件。归并重复内容；详细数值链接已核验报告，迁移唯一证据前确认新位置与链接有效。

项目问题条目保留模块、日期、疑问或复现现象、原因、正确做法、必要例子或出处、当前状态和证据。同类问题合并，复发时补充情境。只记录可观察的代码问题或用户明确暴露的知识缺口。区分待解决、已讲解、代码已修正、功能已验证及独立迁移有证据。功能实测要写清版本、输入和结果；用户自述标明来源。

## 收尾

报告写入的实际位置、完成情况和下次一步。无法保存时给可复制的续接记录，包含项目、当前模块、已完成、待验证、下一动作及依赖。重新写入前核对目标最新版。用户只要求更新背景或结束时，保存完成后结束本轮。
